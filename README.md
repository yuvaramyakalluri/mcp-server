## 1. Project Description

Hello MCP is a simple Model Context Protocol (MCP) server developed using Python. This project demonstrates how to create, configure, and run an MCP server using Visual Studio Code.

## 2. Technologies Used

- Python
- Model Context Protocol (MCP)
- Visual Studio Code
- Virtual Environment (venv)

## 3. Project Structure

```text
Hello-MCP/
│
├── server.py
├── requirements.txt
├── .vscode/
│   └── mcp.json
└── .venv/
```

## 4. Installation and Setup

### Step 1: Create Virtual Environment

```bash
python -m venv .venv
```

### Step 2: Activate Virtual Environment

```powershell
.\.venv\Scripts\Activate.ps1
```

### Step 3: Install Required Packages

```bash
pip install -r requirements.txt
```

### Step 4: Run the Server

```bash
python server.py
```

## 5. VS Code Configuration

1. Open the project in Visual Studio Code.
2. Open `.vscode/mcp.json`.
3. Press `Ctrl + Shift + P`.
4. Search for `MCP: List Servers`.
5. Select `helloMcp`.
6. Start or restart the server.
